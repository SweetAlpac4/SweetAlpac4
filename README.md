## Infrastructure shipped

### Research & Networking

**[Q-Learning-Based Adaptive Routing](https://github.com/SweetAlpac4/sdn-ta)**

QoS-aware adaptive routing for video streaming in
Software-Defined Networks using reinforcement learning.
Evaluated through delay, jitter, packet loss, and throughput.

`Python` `Mininet` `Ryu` `OpenFlow 1.3` `Q-Learning` `Docker`

### Cybersecurity & Industrial Systems

**[VORA — Verification of Restored Automation](https://github.com/0xda3m0ns/VORA)**

Automated functional verification of restored PLC systems
through industrial control logic testing, Modbus TCP
simulation, and structured test reporting.

`Python` `OpenPLC` `Modbus TCP` `PyModbus` `Docker` `Linux`

**[ScanGuard System](https://github.com/maksalarina12/ScanGuard-System)**

QRIS payment verification and fraud detection system
developed for HackNusa 2026. Features payload validation,
CRC verification, merchant identity checks, and risk assessment.

`React` `TypeScript` `Vite` `Tailwind CSS` `Zustand` `Vitest`

### Software Engineering

**[SIFULIN — Informal Business Data Collection System](https://github.com/SweetAlpac4/pendataan-usaha-bps)**

A web-based information system developed during an internship
at Statistics Indonesia (BPS), Langsa City. Supports field
data collection, business verification, interactive mapping,
analytics, and data exports.

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `Auth.js`

**[Ref Manager](https://github.com/SweetAlpac4/ref-manager)**

An academic reference management tool with bibliographic
metadata retrieval, local reference libraries, citation
generation, and open-access PDF discovery.

`React` `JavaScript` `IndexedDB` `Dexie.js` `Citation.js`
